# Monitor Commander

![Monitor Commander 主题预览](preview.png?v=2)

把 [wayjam/komari-theme-commander](https://github.com/wayjam/komari-theme-commander) 移植到
[极简探针 Monitor](https://github.com/monitor-probe/monitor) 的主题：深空指挥台的 HUD 视觉，加上
克制明亮的光明 / 简洁配色，地球 / 网格 / 表格 / 在线时长四套视图。数据全部来自探针的公开接口 ——
实时快照走 WebSocket（连不上自动回退到 `/api/nodes` 轮询），历史曲线与延迟监控走
`/api/nodes/{id}/metrics`；字体与国旗都打进包里，不依赖第三方 CDN。

## 主要功能

- **四套视图**：3D 地球（点阵大陆、区域脉冲标记、中枢弧线）、网格卡片、表格、在线时长排行。
- **实时监控**：卡片展示 CPU / 内存 / 磁盘 / 流量配额 / 负载 / 延迟与上下行速率；WebSocket 实时推送，断线自动重连。
- **节点详情**：环形仪表 + 硬件信息卡片 + 时序图表（CPU、负载、内存 + Swap、磁盘、TCP / UDP、网络流量、Ping 延迟），实时与历史档位可切。
- **网络页**：上下行实时速率、累计流量、连接数变化、面积式流量图。
- **三套配色**：光明（Lumina）/ 深空（DeepSpace）/ 简洁（Clean），可跟随系统；深空带扫描线、脉冲与辉光等 HUD 装饰。
- **备注即标签**：站长在后台把备注写成逗号清单（半角 / 全角逗号、分号、顿号都认），卡片与详情页都会拆成一枚枚标签胶囊，多余的折进「+N」浮层。
- **计费汇总**（默认关闭）：按币种汇总周期费用、月均支出与剩余价值，需登录查看。
- **隐私模式**：一键把节点名替换为随机假名；登录管理员可临时关闭。
- **多语言**：简体中文 / 繁體中文 / English，跟随浏览器。
- **PWA**：可安装到桌面与手机主屏，离线应用外壳 + 最后状态快照。
- **随包资源**：Orbitron / IBM Plex Sans 字体与全部国旗 SVG 都在包里，离线可用。

## 安装

从 [Releases](https://github.com/akanotanin/monitor-theme-commander/releases) 下载 `theme.tar.gz`，
在探针后台「主题」里上传并启用。

## 主题设置

后台「主题」→「主题设置」。所有改动对访客即时生效（切回前台标签页自动刷新）：

| 分组 | 设置项 | 默认 | 说明 |
|---|---|---|---|
| 视图设置 | 默认视图 | 地球 | 访客首访展示的视图；所选视图被关闭时自动回退 |
| 视图设置 | 启用地球视图 | 开 | 关闭后不再出现地球选项 |
| 视图设置 | 地球中枢节点 | 空 | 填真实节点名：该节点被点亮并绘制到其它在线节点的弧线；留空关闭 |
| 视图设置 | 地球旋转模式 | 动态旋转 | 动态自动旋转 / 默认静止（拖拽始终可用） |
| 视图设置 | 减少动效时暂停地球 | 关 | 开启后，系统偏好「减少动效」的访客地球不自动旋转 |
| 视图设置 | 地球标记样式 | 完整 | 完整：脉冲动画 + 速度标签；简洁：扁平标记；极简：仅圆点，CPU 占用更低 |
| 视图设置 | 启用在线时长视图 | 开 | 是否显示在线时长排行 |
| 视图设置 | 启用计费汇总 | 关 | 网格 / 表格视图显示「计费汇总」按钮（仅登录用户可见） |
| 外观设置 | 默认主题 | 简洁 | 光明 / 深空 / 简洁 / 跟随系统（浅色用光明、深色用深空） |
| 外观设置 | 自定义页脚文本 | 空 | 显示在页脚的文本，留空不显示 |
| 外观设置 | 启用隐私模式 | 关 | 所有访客看到的节点名替换为随机假名 |

## 与原版的差异

- **数据源**：从 Komari RPC2 换成极简探针 REST + WebSocket，界面与交互保持上游一致。
- **备注即标签**：探针的节点「公开备注」按逗号拆成标签（卡片与详情页同一口径）；上游的「标签」字段在探针上不存在。私有备注（仅登录管理员可见）保持上游的便签样式。
- **区域标识**：用随包 SVG 国旗渲染 —— Windows 没有 emoji 旗帜字形，直接渲染会退化成「JP」字母对。
- **历史口径**：历史曲线保留 CPU / 内存 / 磁盘 / 网络四类序列（Hub 的存储口径）；Swap、负载、连接数只在「实时」档随页面停留累积。
- **网络方向**：上行 / 下行与 Komari 官方前端口径对齐（上行 = 节点上传速率）。
- **移除不可用能力**：GPU、温度、审计日志等 Komari 专有入口已移除。
- **字体自托管**：Orbitron / IBM Plex Sans 随包分发，不再依赖 Google Fonts。
- **地球防撕裂**：去掉了 canvas 的 `desynchronized` 低延迟直显 —— 它在 Windows + NVIDIA 上会让转动中的地球闪烁。
